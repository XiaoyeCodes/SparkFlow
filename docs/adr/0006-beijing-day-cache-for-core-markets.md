# ADR-0006：核心市场采用北京时间日级分析缓存

- 状态：已采用
- 日期：2026-08-29

## 背景

A 股、港股和美股的近 500 日估值历史，以及比特币长期周期，需要聚合大量历史数据；它们在每次切换时重新请求会造成明显等待。热力图、指数卡、板块强弱和新闻则具有高时效要求，不能使用日级缓存。日股、韩股、印股、德股、法股和英股属于可选国际市场，本次保持其现有展示与刷新行为。

## 决策

- 对 `china`、`hongkong`、`us` 的估值历史，以及 `crypto` 的比特币长期周期使用浏览器持久化日级缓存。
- 缓存日期以 `Asia/Shanghai` 日历日计算；北京时间跨过 00:00 后，旧数据不再命中，首次访问重新获取并替换缓存。
- 内存层合并相同的并发请求，持久层使用 Cache Storage，并在不可用时回退到 localStorage；同一标签页、刷新页面和新标签页均可复用当天数据。
- A 股、港股、美股和加密热力图继续每 3 秒刷新；核心指数卡继续每 3 秒刷新；国际指数维持 5 秒刷新；市场系统状态、新闻和板块强弱也不进入日级缓存。
- 六个可选国际股票市场继续使用原有短缓存和轮询，不改变其展示时效。
- 用户点击刷新按钮属于显式强制更新，可以覆盖当天缓存。

## 结果

同一浏览器在同一北京时间日期内，每个核心市场的历史估值或长期周期数据最多自动请求一次；市场之间反复切换和页面刷新直接读取当天缓存。实时热力图与指数卡仍持续更新，热力图的点击、缩放、行业钻取和全屏逻辑未改动。

应用关闭时无法在午夜主动联网，因此“凌晨更新”具体表现为：北京时间日期变化后的第一次访问触发当日唯一一次自动加载；若应用一直打开，下一次访问相关市场时同样会识别跨日并更新。

## 代价与回退

当天上游数据若在首次加载后修订，页面不会自动追踪该修订，用户可用刷新按钮强制更新。浏览器禁用持久存储时仍保留会话内存去重，但刷新页面后需要重新请求。
