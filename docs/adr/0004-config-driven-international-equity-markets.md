# ADR-0004：配置驱动的国际股票市场页面

- 状态：已采用
- 日期：2026-08-10

## 背景

项目已有 A 股、港股和美股完整页面，也已有全球地球与若干国际市场小型热力图。新增六个国家若分别复制页面，会导致行情刷新、估值逻辑、研究入口和视觉样式逐渐分叉。

## 决策

采用“统一市场页面 + 国家配置”的架构：

- `MarketChartMode` 扩展为十种市场模式。
- `InternationalMarketHeatmap` 根据国家配置复用同一个热力图交互组件。
- 服务端使用国家指数配置和成分股配置生成统一响应。
- 国际市场指数使用 5 秒轮询、3 秒共享缓存和请求合并。
- 估值引擎复用现有区域估值模型，数据源切换为 Yahoo Finance 的指数历史与公司财务时序。
- 地球报价携带市场模式，点击时先展示热力图，再跳转完整市场页面。

## 结果

优点：六个市场功能一致，新增国家只需增加配置；刷新、错误回退和视觉交互可统一演进。

代价：国际市场当前采用代表性龙头样本和静态代表权重代理，不等同于完整交易所成分与授权指数估值；首次估值计算可能需要数秒，之后由缓存加速。

## 后续扩展

当接入正式交易所或商业数据源时，只替换服务端适配器与权重字段，不需要重写页面组件。
