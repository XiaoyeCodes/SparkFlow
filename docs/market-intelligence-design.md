# MarketLens 真实市场情报设计

## 目标

MarketLens 提供可追溯、可降级、可解释的研究辅助。确定性数字由公开数据接口产生；用户配置的 AI 只解释已取得的证据，不能自行补写行情、新闻、研报或因果关系。

## 数据链路

| 模块 | 主来源 | 校验 / 约束 |
| --- | --- | --- |
| 主要指数 | 东方财富实时行情 | 腾讯证券逐项校验，价格偏差不超过 0.25% 标记为 `verified` |
| A 股宽度 | 上证、深证指数上涨 / 下跌 / 平盘家数 | 只用两个交易所市场宽度，避免重复计算沪深 300 和创业板样本 |
| 板块风向 | 东方财富行业资金流 | 分别抽取净流入和净流出各 50 个板块，避免只看榜首造成幸存者偏差 |
| 中文新闻 | 华尔街见闻、36氪、中新财经、中国政府网等 RSS | 保留标题、来源、时间、原文链接；按来源、时效和市场关键词排序 |
| 券商研报 | 东方财富公开研报列表 | 保留机构、分析师、评级、发布日期、EPS 预测和原文链接 |

接口按组独立失败。某一组不可用时，其评分回到中性值并降低总置信度，其他数据仍可显示。完整快照缓存 45 秒，避免连续刷新触发公开接口限流。

## 综合评分

所有维度均为 0-100，50 表示中性：

```text
综合分 = 大盘趋势 * 32%
       + 资金与板块 * 22%
       + 新闻催化 * 18%
       + 机构研报 * 13%
       + 风险余量 * 15%
```

- 大盘趋势：主要指数加权涨跌 68% + A 股上涨家数占比 32%。
- 资金与板块：流入端和流出端样本的资金金额平衡，并保留领涨、领跌证据。
- 新闻催化：中文新闻的来源权重、时效权重和规则化多空词，不用 AI 猜情绪。
- 机构研报：评级映射 72% + 可比 EPS 预测增速 28%，明确保留卖方乐观偏差风险。
- 风险余量：跨市场涨跌离散度、极端单日波动、负面新闻占比和市场宽度。分数越高表示风险余量越充足。

## 投资方法论映射

段永平、巴菲特、芒格、Druckenmiller、Soros 和 Paul Tudor Jones 只作为公开原则的评分框架，不模拟本人发言，也不声称得到本人实时判断。

价值投资需要公司财务、估值、管理层和竞争优势数据。当前页面是市场级快照，因此段永平与巴菲特维度固定降低置信度；趋势、流动性和风险控制维度可以使用当天市场数据，置信度相对更高。

## AI 与 Obsidian

`AI 深度解读` 会把当前快照的 JSON 证据发送到用户在个人设置中选择的模型。提示词要求区分事实、推断和未知，并至少给出两条反证或失效条件。

`写入 Obsidian` 会保存主要指数、评分拆解、资金风向、新闻、研报、方法论映射，以及已经生成的 AI 解读。API Key 仍只保存在浏览器本地设置中。

## 下一阶段

市场级评分回答“今天是否适合承担风险”，不能回答“某只股票是否值得买”。下一阶段应增加自选股研究：交易所公告和公司财报优先，叠加自由现金流、ROIC、负债、估值区间、机构一致预期修正、资金流与价格趋势，再输出个股级综合评分和证据审计结果。

本模块不构成投资建议、收益承诺或自动交易指令。
