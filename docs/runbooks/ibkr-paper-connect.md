## 启动与查看

在项目根目录的两个终端分别运行并保留进程：

```powershell
& ./scripts/start-ibkr-terminal.ps1 -BindingFile ./.sparkflow/ibkr-terminal/bindings.json
npx vite --host 127.0.0.1 --port 5180 --strictPort
```

打开 http://127.0.0.1:5180/ibkr，选择 PAPER。首次启动/服务重启均不恢复交易授权。单实例锁防止两个服务使用同一订单账本；不要为重启而删除锁文件或数据库。

私有绑定与令牌位于 `.sparkflow/ibkr-terminal/`，受当前 Windows 用户 ACL 限制且被 Git 忽略。模板为本目录 `ibkr-paper-bindings.example.json`。brokerAccount 是账户编号；clientId 应为独立正整数，禁止 0；默认 Gateway paper 端口 4002，以客户端实际设置为准。绑定中的 readonly:true 表示启动读取按只读边界运行；人工 paper 交易只能在网页中单独确认风险范围、逐笔预览和精确订单后走独立风控/确认接口，live 仍无写入路径。

## 人工模拟盘订单

打开顶栏“订单”，输入用户选择的股票/ETF 代码，查询并核对合约。展开“设置本次模拟盘风险范围”，自行填写单笔金额、账户敞口、集中度、日亏损、频次、偏价和手续费预留，选择有效期并确认范围。金额不预填，不替用户选择额度；最多 8 小时，只适用于所选合约。

再填写整股数量、方向和限价，生成预览。预览不会发单。核对具体账户与全部条款，勾选精确订单确认后点击“确认后发送至 IBKR 模拟盘”，才会尝试经本地风控与原生 SDK 提交。当前仅支持 USD 美股/ETF、整股、只做多/卖出现有持仓、DAY 限价、常规交易时段；不支持做空、杠杆、期权或自动策略。风险范围确认只打开当前 paper 会话的人工写入边界，不打开 live。

风控要求真实逐笔成交报价的券商时间戳、当日 PnL、已结算现金和完整账户/合约信息；行情最多 10 秒、账户最多 30 秒。休市、数据权限不足或缺数据会拒绝发送，不用延迟行情替代。当前有任意挂单时保守拒绝新增风险，剩余挂单风险与完整账户证明仍需后续实现。

SUBMITTING 只是提交待确认，ACKNOWLEDGED 才代表已匹配券商回报，成交另看执行状态。超时/中断为 UNKNOWN，保留预占并先对账；重复同一确认只读原记录，禁止另建相同订单盲目重试。本系统已识别的订单可单独确认撤单，撤单期间仍可能成交；原生改单尚未接通。

“停止新增订单”不会撤单或平仓。现有订单继续跟踪，撤单单独确认。风险范围重设/停止后重开暂需重启账户服务；重启不会恢复旧授权，但保留账本与未决订单。
