# IBKR 账户分析工作台

入口为 `/ibkr`，仅提供账户分析工作台。原交易终端入口、页面组件、订单／策略／回测前端、旧接口代理及对应界面测试已删除；旧的 `terminal=legacy` 参数不再切换页面。TWS/Gateway 共用的本地账户服务和快照协议继续保留。

## 首次连接

1. 启动 SparkFlow 本地服务，打开「设置」，选择官方 MCP，点击「连接 / 重新授权 IBKR」。
2. 在 IBKR 官方页面登录并授权。应用只申请 `mcp.read account-ids`，使用 OAuth PKCE 和十分钟有效的单次 state。授权不授予交易权限。
3. 回到工作台选择授权账户，核对持仓数量、币种和账户摘要。只有成功读取并校验 JSON 数据后才显示账户已同步。授权成功但工具或字段不兼容时，设置页保留诊断信息。
4. 核对现有 Vibe-Trading 的提供方和模型、发送字段与调用预算，再开启账户 AI 分析。投资偏好未填写完整时，只提供条件式方案。

官方地址：`https://api.ibkr.com/v1/api/mcp-public`。官方元数据声明支持动态客户端注册、PKCE S256、刷新令牌及撤销端点。刷新令牌支持不等于永久在线；实际授权时长由 IBKR 决定。

2026-09-07 已复用用户完成的真实授权，成功读取官方 MCP 的持仓、账户摘要及逐币种现金。当前官方工具为 `get_account_positions`、`get_account_summary`、`get_account_balances`，均声明只读、无参数，作用于当前授权账户；没有账户列表工具。适配器仅接受这三个名称、只读标记及无参数结构完全匹配的工具，另保留显式账户参数协议的适配。未知结构、分页、重复合约和账户范围变化均拒绝发布快照。

官方响应使用 snake_case 字段，现金中的 `BASE` 是汇总行，不与逐币种现金累加；组合未实现盈亏取券商 BASE 汇总，缺失则留空。接口未返回券商账号，页面明确标为「当前授权账户（账号未提供）」，由用户对照券商持仓确认。使用加密存储中的本地授权标识隔离数据，刷新令牌与服务重启保留该标识；重新完成授权时创建新标识，不把无法确认同一账户的历史记录自动合并。令牌续期和撤销仍需后续实际验证。

如果使用 TWS/Gateway，按原有 `ibkr-live-readiness.md` 配置 8765 本地只读服务。两种来源由用户选择，不自动切换。资产类型无法识别时展示原始持仓，不假设为股票。

## 运行与数据

- 账户每 60 秒同步；失败指数退避，最多 15 分钟。保留最后成功快照，三分钟未取得新快照即标为过期并暂停新分析。
- 可见页面每五秒获取批量参考行情；页面隐藏时暂停高频行情。五秒表示采集频率，东方财富免费来源可能延迟或休市。报价时间与取得时间分别保存。
- 后台每十五秒检查任务；运行于 Vite 开发服务或预览服务中，浏览器关闭不影响执行。仅部署静态 `dist` 不具备后台能力。服务停止、休眠、关机期间不执行任务。
- 日报按纽约交易日、夏令时及半日市，在收盘后 30 分钟生成。启动后只补最新应生成的一期；生成失败至少 30 分钟后才重试，并受每日总预算限制。当前复用项目 **2026 年交易日历**，其他年份暂停自动日报并提示更新。
- 事件补充分析默认一天最多四次、间隔至少六十分钟；手动、日报、事件和追问共享默认每天十二次总预算。规则提醒不受模型预算影响。
- AI 只调用 Vibe-Trading 的模型工厂，不启动交易 Agent、不挂载交易工具、不存储研究会话中的账户上下文；模型调用关闭 LangSmith tracing。记录模型指纹，提供方、模型或端点变化后原授权失效。
- 净值、现金、成本和盈亏使用 IBKR 口径。外部行情单独展示；未转换币种不相加。没有完整历史净值、出入金或 ETF 成分数据时，不计算虚构的回撤、收益率或穿透风险。
- 调整计划统一计算所有目标的现金、仓位及行业影响，检查现金底线和多头可卖数量。未取得可靠碎股交易精度时仅显示金额与权重，不提供精确股数；不含手续费、滑点及税费。

## 存储与接口

本地目录 `.sparkflow/ibkr-workbench` 不提交 Git。Windows 目录仅授予当前用户权限，OAuth 凭据使用 DPAPI CurrentUser 加密；其他系统使用目录 0700、凭据文件 0600。账户状态和完整报告含持仓信息，保存在受限目录中。持久化为原子替换，后台使用 PID 锁避免重复工作进程。

接口前缀 `/api/ibkr-workbench/`：

- GET `state`、`quotes`、`history?conId=&period=`、`performance`、`research/{jobId}`、`reports/{id}/{json|markdown|html}`。
- POST `connect`、`disconnect`、`source`、`sync`、`preferences`、`consent`、`alerts`、`analyze`、`cancel`、`resume`、`plans`、`simulate`。
- GET `oauth/callback` 仅允许带有效 OAuth state 的官方登录返回；其他接口严格检查 loopback Host、Origin 和 Fetch Metadata。

授权令牌不返回前端。断开时尝试远端撤销并清除本地凭据；撤销结果不确定时提示用户在 IBKR Manage Third-Party Consents 核对。关闭 AI 后停止新请求，无法收回已发送给模型提供方的内容。历史报告最多在页面展示最近二十份，原始 JSON 报告继续留存在本地受限目录。

## 验证

- `npm run test:ibkr:workbench`：离线模型、OAuth 状态、工具权限、分页、账户隔离、日历、预算、去重与恢复。
- `npm run test:ibkr:e2e`：工作台空态、持仓详情、设置、PDF 下载、桌面和手机布局，以及旧终端入口已移除。
- `npm run test:ibkr:unit`：共用快照、本地请求边界及 TWS/Gateway 服务的 JS/Python 测试；该脚本需要支持 `--experimental-strip-types` 的 Node，推荐 Node 24。Python 测试依赖见 `services/vibe-trading/requirements-ibkr-test.txt`。
- `npx tsc -b` 与 `node node_modules/vite/bin/vite.js build`。

后续真实验收需要用户对照 IBKR 核对持仓和账户摘要，并验证授权续期、撤销及开启模型分享后的报告输出。离线测试数据只存在测试目录和被浏览器测试拦截的响应中，不注入生产服务。

## 主动研究 V2（2026-09-07）

界面采用黑色背景 #050A09、墨绿卡片 #0B1411、边框 #20352D 和薄荷绿 #70DCBA。账户总览、AI 分析、机会与风险、持仓、设置独立导航；1920、1440、808 和手机布局使用同一套响应式组件。

研究只调用 `scripts/ibkr-ai-analysis.py tool` 的明确白名单：搜索、阅读、公司资料、基本面、财报、历史行情和 SPY/QQQ 复权数据。没有交易、命令或通用 Agent 权限。搜索提供方复用 Vibe-Trading 配置（IQS 或 ddgs 多引擎及回退服务），原文由 Jina Reader 获取，公司资料由 Yahoo Finance 提供，财报来自 SEC EDGAR。公开工具不接收账户快照、资金或账号。

日常研究覆盖前三大仓位和风险命中的美股／ETF；手动深度研究覆盖所有支持的持仓。查询最近七天事件，深度研究另查最新财报。先收集资料，再将完整组合一次性交给 Vibe-Trading 配置的模型，生成结论、三段简报、机会风险和行动建议；最多展开三个影响决策的标的，不要求逐仓报告。模型收到的是去除账户标识的持仓和经授权的指标。输出保留结束原因，分别识别截断、JSON、字段、引用和持仓覆盖错误；逐仓观点必须有可在原文中逐字找到的支持摘录。

每个新任务正常只调用一次模型，校验失败最多再修复一次。日常资料收集限制12次搜索、12次原文、5分钟；深度限制30次搜索、36次原文、15分钟。公开工具最多并发三个；每次模型调用前先持久化预算占用，修复计入日预算，单次章节生成最多修复一次。用户主动继续任务复用已搜集资料；旧任务迁移到组合分析，保留旧章节作历史记录。日预算耗尽时，手动任务可明确选择“额外调用1次并生成报告”，仅该次请求有一次额外额度，写入manual-extra用量记录，不修改每日预算，不供后台自动任务使用。超时、预算不足、取消及服务重启后可查看阶段证据；未完成任务不替换上一份完整报告。研究报告的 `version:2` 与旧版报告兼容。

PortfolioAnalyst 适配明确限定无参数且只读的 `get_pa_performance_all_periods`。实际已验证官方 `accounts.account.periods` 结构与分数形式的 `cps`。`start_nav` 可为零，净值始终读取 `nav` 数组。TWR 支持区间重基，与美元 SPY/QQQ 复权日收盘数据对齐；MWR 只展示原始累积序列，不进行区间重基或基准比较。至少 60 个共同收益观测后才计算波动率倍数；历史不可用时记录本地净值，不把净值变化当收益。

完整报告可导出含证据链接与检索记录的 HTML/PDF。调整计划仅保存条件与目标，不发送订单。价格条件只有行情新鲜且所有相关条件可以程序判定时才自动提示；财报和政策等条件由用户核验。
