# ADR: 美国宏观卡片独立数据通道

## 状态

已采用（2026-08-14）。

## 背景

PPI、CPI、失业率、非农、PMI、PCE 曾分别来自宏观分区、PMI 分区和官方发布同步补丁。多个异步响应通过同一个 Dashboard 数组合并，较晚返回的不完整对象可能覆盖已解析出的前值或预期，造成修改一项后其他卡片显示“待更新”。

## 决策

六张卡采用独立的 stale-while-revalidate 通道。每张卡拥有唯一生产函数、独立请求键、独立内存缓存、独立进行中的请求以及持久化的最后有效快照。前端为六个 ID 分别请求并写入独立状态，不再从宏观 Dashboard 的分区合并结果读取卡片数据。

只有实际值、前值、预期和变化全部解析成功且周期一致时，新快照才可替换旧快照。刷新失败时返回该卡自己的最后有效快照，不生成“待更新”，也不修改其他卡片。

## 取舍

- 优点：消除跨卡覆盖；单一来源失败被限制在单卡；重启后可立即使用磁盘快照；字段计算保持内部一致。
- 成本：增加六个轻量请求和一份忽略版本控制的运行时快照；现有 Dashboard 数据链仍保留给其他页面模块。
- 运维：客户端每 60 秒独立检查；服务端一分钟内直接返回缓存，过期后后台刷新；接口测试验证六卡字段完整性与变化值计算。
