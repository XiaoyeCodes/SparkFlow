# ADR: 美国宏观卡片独立数据通道

## 状态

已采用（2026-08-14）。

## 背景

PPI、CPI、失业率、非农、PMI、PCE 曾分别来自宏观分区、PMI 分区和官方发布同步补丁。多个异步响应通过同一个 Dashboard 数组合并，较晚返回的不完整对象可能覆盖已解析出的前值或预期，造成修改一项后其他卡片显示“待更新”。

## 决策

六张卡采用独立的 stale-while-revalidate 通道。每张卡拥有唯一生产函数、独立请求键、独立内存缓存、独立进行中的请求以及持久化的最后有效快照。前端为六个 ID 分别请求并写入独立状态，不再从宏观 Dashboard 的分区合并结果读取卡片数据。

实际值与统计期确认后即可替换旧快照；前值、预期为可选补充，缺失显示“—”，不得阻塞实际值更新。BLS 提供 CPI、PPI、非农和失业率实际值；PCE 优先使用 BEA，同期或更新的市场数据可作为明确标记来源的补充；PMI 使用 ISM Manufacturing PMI 的市场日历记录。市场补充仅在统计期和实际值一致时使用，前值优先使用官方修订数。历史回补仅允许紧邻上一统计期，不能跨月计算变化。

快照不得回退到更早统计期。刷新失败时返回该卡自己的最后有效快照，并设置 stale、checkedAt 和 refreshError；成功时间 lastSuccessAt 与统计月份 updatedAt 分开保存。根据用户的显示偏好，卡片保持原有布局，不增加日期或刷新状态行；这些诊断字段保留在接口和服务端快照中。同周期且实际值未变化时，可保留已经取得的预期；跨周期不得沿用。

## CPI 备用通道（2026-10-13）

BLS 新闻稿遭遇403时，CPI独立卡改用FRED转发的BLS官方序列。两条序列并行读取：未季调 `CPIAUCNS` 用于同比，季调 `CPIAUCSL` 用于环比；分别要求去年同月和紧邻上月的实际指数，取两条序列最新共同统计月，不跨缺口计算、不拼接不同月份。前值为上月同比；预期仍只接受同月且与实际值匹配的日历值，缺失显示“—”。来源链接、计算口径和原统计期随卡片保存。

新闻稿与备用通道同时启动，主来源有3秒首屏预算；超过预算且备用成功时返回备用结果，共享新闻稿抓取继续在后台执行。若此时已取得同期或更新的有效新闻稿，则优先使用新闻稿；所有来源失败时仍遵守已有stale回退及统计期不倒退规则，不把旧统计期改成抓取日期。检查入口：`npm run test:cpi-fallback`、`npm run test:macro-release`。

口径依据：[CPIAUCSL](https://fred.stlouisfed.org/series/CPIAUCSL)、[CPIAUCNS](https://fred.stlouisfed.org/series/CPIAUCNS)、[BLS CPI 说明](https://www.bls.gov/cpi/)。2026-10-13本机验收恢复到2026年8月已发布数据，同比3.4%、环比0.4%；后续值由来源更新，文档数字不作为程序默认数据。

## 取舍

- 优点：消除跨卡覆盖；单一来源失败被限制在单卡；重启后可立即使用磁盘快照；字段计算保持内部一致；预期缺失不再冻结实际值。
- 成本：增加六个轻量请求和一份忽略版本控制的运行时快照；现有 Dashboard 数据链仍保留给其他页面模块。
- 运维：客户端每 60 秒独立检查；服务端一分钟内直接返回缓存，过期后后台刷新。运行 `npm run test:macro-release` 验证新闻稿措辞、缺失预期、修订前值、周期防回退及失败恢复；运行 `npm run test:macro-cards` 强制刷新并验证六卡真实接口。可设置 `SPARKFLOW_EXPECT_EMPLOYMENT_PERIOD=YYYY-MM` 检查发布后的就业统计期。
