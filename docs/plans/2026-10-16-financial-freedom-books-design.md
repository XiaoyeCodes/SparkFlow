# 推荐书籍：Financial_freedom 阅读入口

## 目标与范围

在现有推荐书籍页接入 `codeman008/Financial_freedom` 的 15 本书、17 个 PDF，点击卡片即可站内阅读。

新增“投资与财富管理”分类；《穷查理宝典》和《纳瓦尔宝典》沿用现有分类、介绍和卡片，只补充阅读文件。不同版本归在同一本书下。没有 PDF 的原有书籍继续打开介绍。

## 实现选择

- 采用现有 `pdfjs-dist` 实现站内阅读，支持页码跳转、翻页、适合宽度、缩放和版本选择，兼容电脑、平板和手机。
- 阅读器和 PDF worker 单独打包，悬停或聚焦可预热阅读器模块，用户打开书籍时才获取 PDF。
- 不复制 PDF 到仓库或用户数据目录。原始文件由浏览器直接从 GitHub 获取，固定到已验证的源版本 `322f1bc132e879e8ddbf4485d6a931735622f086`，并保留每个文件的来源链接。
- 网络错误和超时展示重试、原始 PDF 与 GitHub 来源入口；关闭或切换版本时取消旧加载及渲染。单页按需绘制，限制高分辨率画布尺寸。

## 验证

- 6 项浏览器测试：17 个链接、三个屏幕尺寸下的阅读/翻页/缩放、已有书籍去重与版本切换、加载失败及重试。
- 自动生成测试 PDF，不将源书籍内容写入测试夹具。
- 源仓库文件名逐项比对、17 个原始文件链接的 HTTP 状态及 CORS 检查。
- 真实文件在线打开与翻页抽查：《富爸爸，穷爸爸》《纳瓦尔宝典》。
- TypeScript 检查与生产构建。
