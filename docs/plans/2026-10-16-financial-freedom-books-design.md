# 推荐书籍：Financial_freedom 阅读入口

## 目标与范围

在现有推荐书籍页接入 `codeman008/Financial_freedom` 的 15 本书、17 个 PDF，点击卡片即可站内阅读。

“投资与财富管理”分类置顶显示全部 15 本书；《穷查理宝典》和《纳瓦尔宝典》移到该分类，保留原有介绍，其他分类不重复展示。不同版本归在同一本书下。没有 PDF 的原有书籍继续打开介绍。

## 实现选择

- 采用现有 `pdfjs-dist` 实现站内阅读，支持页码跳转、翻页、适合宽度、缩放和版本选择，兼容电脑、平板和手机。
- 阅读器和 PDF worker 单独打包，悬停或聚焦可预热阅读器模块，用户打开书籍时才获取 PDF。
- 按用户要求，将 17 个 PDF 预先下载到 `UserData/books/financial-freedom/322f1bc132e879e8ddbf4485d6a931735622f086/`。运行 `npm run books:download` 可补齐或修复文件，已验证的文件不会重复下载。下载使用 7890 代理，校验文件长度、PDF 头和结束标记，完整文件才原子写入。
- 阅读器及“原始文件”入口只读取同源 `/api/books/financial-freedom` 本地接口。接口不访问 GitHub，不依赖浏览器代理，允许列表限定为这 17 个文件；支持 GET、HEAD 和字节范围请求。文件缺失或不完整时明确报错。
- 文件保存在已被 Git 忽略的 `UserData`，跟个人数据一并备份，不加入代码提交；在另一台电脑安装时需要复制该目录或主动执行下载命令。
- 关闭或切换版本时取消旧加载及渲染。单页按需绘制，限制高分辨率画布尺寸。
- 中文字符映射（CMap）和标准字体通过本地接口从已安装的 `pdfjs-dist` 提供，不访问字体 CDN。

## 验证

- 6 项浏览器测试：17 个链接、三个屏幕尺寸下的阅读/翻页/缩放、15 本书全部置顶且去重、版本切换、加载失败及重试；测试中禁止浏览器访问 GitHub 原文件。
- `npm run test:books` 验证本地接口全量/HEAD/范围读取、缺失和损坏文件处理、路径允许列表及服务重启后的文件读取。
- 自动生成测试 PDF，不将源书籍内容写入测试夹具。
- 源仓库文件名逐项比对、17 个原始文件链接的 HTTP 状态及 CORS 检查。
- 真实文件本地打开和翻页检查，浏览器阻断全部外网请求。
- TypeScript 检查与生产构建。
