# SparkFlow 每日简报实施计划

## 验收标准

- `/council` 可从顶部“每日简报”进入，默认展示总览。
- 页面在桌面和移动端无横向溢出，卡片为蓝黑半透明圆角风格，颜色不过度偏绿。
- 实时市场带与每日快照相互独立；快照缓存不得改变热力图、指数和加密行情的原刷新频率。
- 同一日期/时段重复请求命中磁盘缓存，并发请求只生成一次。
- 08:00、18:00 自动生成；外部调度接口有 secret 或 localhost 限制。
- AI 未配置时仍可完整使用，且清楚标注摘要来源。
- IBKR 未连接不报错；连接后可只读显示持仓摘要，不暴露完整账户号。
- TypeScript、构建和每日简报专项验证全部通过。

## 实施步骤

1. 新增 `server/dailyBriefService.ts`：时区/时段计算、日期化缓存、锁、并发去重、清理、调度器。
2. 在 `vite.config.ts` 注入现有行情、新闻与 IBKR loader，新增简报查询、刷新和状态接口。
3. 新增 `src/lib/dailyBriefTypes.ts`，统一前后端数据契约。
4. 新增 `src/routes/DailyBrief.tsx` 与独立 CSS，实现四个 hash 视图和实时市场带。
5. 启用 `/council` 路由，将导航文字改为“每日简报”。
6. 新增 GitHub Actions 定时工作流与环境变量说明。
7. 新增锁/缓存/时段专项测试，运行构建并用浏览器截图检查布局。
8. 只提交本次新增和明确修改的文件，保留用户现有的热力图与全局样式改动。
