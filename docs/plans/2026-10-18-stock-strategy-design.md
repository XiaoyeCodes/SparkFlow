# 股票市场：市场情报与策略研究

## 已确认目标

股票市场提供两个子页面。现有行情、热力图、新闻等保留在 `/market`（市场情报），
新增 `/market/research`（策略研究）。使用 daily_stock_analysis 的实际 Python 分析引擎，
以 SparkFlow 原市场页面的深色、蓝青色强调、圆角界面重做研究工作台，不嵌入上游网页。
保留大标题切换按钮并取消重复的顶部导航留白；市场情报其余样式恢复原版。

## 实现

- 固定上游版本 7a21cd76952c7fe44a7fc5a6113a5b2b8a16bb32，保留 MIT 许可和来源。
- 独立 Python 环境，避免影响 Vibe-Trading。直接调用 AnalysisService 和 AgentExecutor。
- 个股报告、15 种策略选择、策略问答、任务进度、取消、历史报告和 Markdown 导出。
- 服务端每次启动任务读取现有模型设置。密钥通过 stdin 传入隔离子进程，不写入任务文件、命令行或浏览器响应。
- 任务和 SQLite 数据放在 UserData/strategy-research。报告先持久化再返回；刷新与离开页面不重新触发收费任务。
- 单服务串行队列、重复任务去重、超时与退出处理。重启后未完成任务标为中断，不自动重复调用 AI。
- 禁用通知及定时任务，仅用户点击触发。行情或新闻不可用时展示上游实际错误/覆盖说明，不编造分析。
- 统一子导航，窄屏上下布局；模型设置复用已有设置面板。
- 独立适配腾讯/新浪美股数据、东方财富财报与 Google/Bing 新闻 RSS，公共数据代理与模型代理分离。
- 历史报告兼容平铺字段与 Agent dashboard 字段，页面和导出统一映射，不修改历史原文。

## 验证

TypeScript 编译、生产构建；后端队列/持久化/取消/错误/密钥脱敏测试；Python 实际引擎导入与配置适配检查；
浏览器验证两个入口、选择策略、发起任务、历史恢复、问答、错误反馈与手机布局。
