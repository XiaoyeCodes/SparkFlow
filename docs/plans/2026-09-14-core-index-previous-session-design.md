# 核心指数等待开盘时保留上一交易日涨跌幅

用户要求当天未发布行情时显示上一交易日涨跌幅，直到当天开盘有数据；保持 UI 和 3 秒刷新方式。

基于已观察到的新浪整组清零结构识别占位数据：美股指数涨跌额、涨跌幅、今开、最高、最低皆为零，且点位仍等于昨收。过滤这种占位而不误伤有有效开盘价的真实 0% 行情。不通过北京时间日期或固定夏令时开盘时间推断交易日，因此适用于周末、节假日及延迟发布。

沿用现有 Yahoo 备用最新交易日快照；快速备用源失败时从缓存的两条有效日线收盘恢复涨跌幅，保留来源与原日期，并限制为 14 天内数据。没有足够有效数据时返回不可用，不能编造 0%。新浪发布当天有效行情后自动恢复主源。

测试占位清零、真正平盘、开盘后涨跌、周末跨日的上一交易日恢复、历史不足和过期、UI 数值切换与链接/曲线保持。暂不提交或部署。
