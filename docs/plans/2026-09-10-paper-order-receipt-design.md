# 模拟订单回执

用户确认发送后，将确认弹窗切换为订单回执；回执显示股票、买卖方向、数量、委托价格、订单编号、已成交数量、成交均价和本地更新时间。沿用交易页的深色背景、薄边框和状态色。关闭后可从订单列表重新查看。

发送确认、券商受理、部分成交和全部成交分别呈现。成功状态来自服务端的 SDK 发送记录或券商回报；HTTP 200 或预览完成本身不代表成交。缺失的成交价格保持“待回报”。断网、未知状态和拒单保留可核对的回执，不自动重发。

现有账户范围状态轮询更新当前回执，通过订单意图 ID 匹配。切换账户时清理回执和旧请求；确认响应到达后使更早发起的状态请求失效。确认接口及订单状态接口统一返回已有成交记录派生的显示字段和持久化发送状态。

验证使用离线订单与浏览器接口模拟，覆盖已发送到成交的更新、部分成交、拒单、未知结果、刷新失败、重复点击、列表重新查看、账户切换以及窄屏布局。本任务不实际提交券商订单。

验证结果：回执浏览器用例 8 项通过；布局修正后重跑桌面、窄屏及原有限价/市价确认流程 4 项通过；回执状态单元用例 5 项通过；Python 终端回归 337 项通过；TypeScript 检查与生产构建通过。另在本机页面打开已有成交订单回执，确认编号、成交数量、成交均价与服务端记录一致；未发送新订单。截图位于 `output/ibkr/order-receipt-existing.png`、`output/ibkr/order-receipt-filled.png` 和 `output/ibkr/order-receipt-mobile.png`。
