# IBKR 每日账户简报

运行版本 `portfolio-daily-brief-v4`。实际指令位于 `server/ibkrBriefPrompt.ts`，输出与本地来源校验位于 `server/ibkrBrief.ts`。

每日简报自动读取已同步的 IBKR 持仓快照；用户不需要粘贴持仓。发送给模型的数据只含脱敏后的账户净值、持仓权重、未实现盈亏、现金占比、已取得的 IBKR TWR（如有）及已核验的持仓关联事件。

每日简报只输出：

- 一句账户状态：区间 TWR（仅在 IBKR PortfolioAnalyst 已提供时）、持仓集中度和现金占比；
- 最多三项来自实际持仓的风险提示，包含触发值和观察动作；
- 与持仓直接相关且有原文来源的市场事件；
- 固定免责声明：`⚠️ 以上内容仅供参考，不构成任何投资建议，投资有风险，决策需谨慎。`

它不超过 200 个汉字（免责声明除外），不生成长篇宏观、估值、行业、逐标的报告、事件日历、价格目标、收益预测、风险评分或交易指令。没有足以改变判断的新证据时，会明确说明并保持简短。

账户金额和权重优先通过程序提供的事实占位符引用。模型不得自行书写或换算账户数值；外部数字也默认不写入正文。仅基于账户快照的风险卡应引用相应的持仓／现金／集中度／盈亏／TWR 事实；涉及事件的提醒仍须给出可逐字核对的原文摘录和来源编号。模型遗漏账户事实占位符或超过 200 字目标时，简报仍会发布，并在来源区提示以 IBKR 快照为准；这不会再过滤整条账户风险。缺少可核验来源、持仓归属或结构字段的外部事件提醒会隐藏，并在数据缺口中说明；未能与来源核对的外部数值会隐藏而不展示。只有结构化输出无法解析时，才保存在本地失败记录中，不覆盖上一期成功简报，也不自动追加模型调用。

公开研究仅发送证券代码和公司名称；发送账户事实到模型仍受账户数据分享授权和单次调用预算限制。简报只读，不会下单或修改账户设置。已生成但因旧校验未发布的同版本本地结果可在当前模型授权仍有效时恢复，不会再次调用模型。
