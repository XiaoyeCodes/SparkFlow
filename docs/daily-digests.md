# 地球页金十财经早餐

地球页工具栏在 AI 按钮后增加「金十财经早餐」按钮。当前入口只展示金十早餐，不显示顶部标题栏、切换标签、缓存状态和下次更新时间。AIBase、每日60秒不在地球阅读区展示；共用数据服务和已有缓存仍供独立的每日新闻弹窗使用。

阅读页采用原创深色编辑排版：暖白文字、宋体标题、细线分区和少量陶土色强调。中间报告最大780px，行情和正文占用同一列、保持等宽。宽屏章节目录移至正文左侧外部，滚动时吸顶；左侧线稿缩短并随上方内容滚走，给目录留出位置。空间不足时目录改为正文上方横排、隐藏两侧装饰，始终不压缩正文列。阅读区原生滚动并隐藏滚动条，支持键盘、窄屏和来源链接，Esc/关闭返回入口焦点；样式更新不触发重新抓取。

## 时间与更新

全部按北京时间 UTC+08，不依赖服务器操作系统时区。

| 来源 | 每日更新 | 内容校验 |
| --- | --- | --- |
| 金十财经早餐 | 08:00 | 同日原文、完整五个章节、原文完整性、行情证据 |
| 每日60秒（独立弹窗） | 09:00 | 同日 JSON、全部新闻、官方农历 |
| AIBase（独立弹窗） | 18:00 | 绝对发布日期、完整标题及提要 |

服务启动先读取持久缓存，随后检查最近一次已到期的日期。错过更新时间且没有该期成功缓存时自动补生成；首次启动在更新时间之前，会准备上一已到期日的内容。已有当期缓存不重复生成。后台每 30 秒检查到期任务，正常调度误差最多约 30 秒，另加来源实际抓取和生成时间。

生成任务通过来源锁避免多个进程重复执行；内部保留原技能的候选抓取并行和备用源规则。浏览器访问和状态轮询均不启动生成。打开阅读区后每 30 秒读取轻量状态，生成期间每 10 秒读取一次，新版本成功后才切换文档，不重置阅读位置。

源站可能晚发布、周末不发布或网络不可用。首次失败约 5 分钟后重试，此后 10、20、30 分钟，间隔上限 30 分钟。失败继续显示上一份成功缓存与真实来源日期，不把昨日内容标成今日。没有成功缓存时显示等待/重试入口；详细运行状态仍可从 API 读取。新日期到期后重新尝试，不受上一日期退避时间影响。

缓存包含原文 HTML/TXT/结构化数据和版本校验值，原子写入 `UserData/reports/daily-digests/<id>/latest.json`。金十的行情与正文在同一份快照内提交，读者不会看到不同期数据混合。遵循 `SPARKFLOW_USER_DATA_DIR`。原始新闻抓取证据位于各来源 `runs/`，最多保留最近约七次运行，成功缓存独立保留。用户可下载包含本期行情、时间和完整原文的文本，点击来源查阅原文。

## 运行

首次执行 `npm run digests:setup` 创建独立 Python 3.11 环境，仅安装锁定的 lxml 和 tzdata。`npm run dev`、`npm run preview` 自动执行环境检查。无新增常驻 Python 服务、无付费模型请求、无邮件发送、无账户读取。

项目服务需要运行才能按时更新；关闭后重新启动会补生成。CF 内网穿透只转发页面和缓存读取，不承担生成任务。

国内 AIBase、金十、Daily60、新浪、腾讯主源直连；海外源使用项目相同的本机代理默认 `http://127.0.0.1:7890`。可在启动前设置 `SPARKFLOW_DIGEST_PROXY` 指定代理，或设为 `direct` 全部直连。TLS 校验始终开启。

## 金十行情覆盖

行情**仅在生成金十日报时采集一次**，和新闻抓取并行。正常每日北京时间 08:00；错过时启动补生成。访问、切换标签、重启恢复已成功的当期缓存、状态轮询均不会请求行情源，无分钟行情刷新任务。旧版不完整的当期缓存会一次性升级；成功后当天不再重复生成。失败按日报生成的退避计划重试。

| 品种 | 主源 | 备用源 | 显示口径 |
| --- | --- | --- | --- |
| 纳斯达克综合 | 新浪 `$ixic` | 腾讯 `.IXIC`、Yahoo `^IXIC` | 现金指数，较前收盘；不是纳斯达克100 |
| 标普500 | 新浪 `$inx` | 腾讯 `.INX`、Yahoo `^GSPC` | 现金指数，较前收盘 |
| 科技七巨头 | 新浪 `MAGS` | 腾讯、Yahoo `MAGS` | MAGS ETF，美元 |
| 上证指数 | 新浪 `sh000001` | 腾讯、Yahoo `000001.SS` | 上证指数，较前收盘 |
| 恒生指数 | 新浪 `rt_hkHSI` | 腾讯、Yahoo `^HSI` | 恒生指数，保留来源时间及延迟说明 |
| 比特币现货 | Coinbase BTC-USD 24h统计与最新成交校验 | Kraken BTC/USD 已完成5分钟线 | 同市场、同口径24h变化；不是其他币种或合约 |
| 现货黄金 | 新浪 `hf_XAU` 伦敦金现货 | GoldPrice USD现货 | 美元/盎司，现货参考价 |
| 布伦特原油 | 新浪 `hf_OIL` 连续期货 | Yahoo `BZ=F` | 美元/桶；明确标示具体期货品种 |
| 10年期美债 | 美国财政部日度 CMT 10 Yr | FRED DGS10 | 日度收益率及较前次公布的基点变化；不是 TNX |

上传技能的原始合约约束仍保留在 vendor 目录；项目采用上表公开市场参考口径，不将不同来源伪称为技能指定的 Paxos、London MidPoint 或 ICE 近月合约。报价详情显示实际来源、品种、比较口径、来源时间/官方公布日与采集时间。

主源请求并行，只有缺失品种才使用备用源。校验价格正值、涨跌与前值一致、品种/币种、交易所时区与交易日、来源时间；拒绝未来报价和交易结束后仅有早盘的数据。Yahoo 用报价交易日前一根日线收盘比较，不使用跨月区间起点。BTC统计快照不伪造成交时间；美债按官方日期和列名读取最近两次实际公布值。

每条行情保存响应 SHA256 和相关原始字段。`markets.json` 作为生成器的上次成功报价池原子保存，读取接口仅返回**已成功提交的日报快照**。主备失败时保留原始时间并标注缓存，不改成当前报价、不填零或样例。生成阶段报价池保留上限：证券/商品14天、BTC15分钟、美债8天；缓存池无效或无法凑齐九项时，本次整份生成失败并保留上一份成功日报。成功发布的日报作为当期快照保留至下一期成功更新，不因阅读时间经过而清空行情。

## API

- `GET /api/daily-digests`：共用日报服务的来源状态、缓存日期、下次计划与重试时间，不包含大文档。地球阅读区仅使用金十条目。
- `GET /api/daily-digests/jin10/article`：本机结构化正文，供原生阅读页使用。
- `GET /api/daily-digests/markets`：已提交金十日报的行情快照，只读。
- `GET /api/daily-digests/{id}/document`：兼容用缓存 HTML，非当前阅读页。
- `GET /api/daily-digests/{id}/text`、`data`：下载文本或结构化数据。

仅允许 GET/HEAD，无对外生成或行情刷新接口。原生阅读页从 inert template 解析金十原文，仅渲染有限语义标签，丢弃脚本、源站图片、事件、原始样式和非HTTPS链接。兼容 HTML 接口使用无脚本 CSP。浏览器断开不影响后台任务；服务器停止会中止子进程，不提交半成品。

## 验证

`npm run test:digests` 检查北京时间边界、启动补生成、并行、锁、重启恢复、失败回退、停止行为、已禁用来源不生成、行情品种/前值/时间、主备来源与只在生成时抓取。浏览器测试 `daily-digests.spec.ts` 验证金十入口、九项行情、隐藏顶部栏、两侧线稿、键盘、隐藏滚动条、生成中保留阅读位置、成功换版、失败缓存及窄屏。`node scripts/verify-daily-digests-live.mjs` 在运行中的项目核验真实九项行情和2200/1440/768/390宽度截图。原始技能核心测试和桥接层测试位于 `services/daily-digests/`。

Python 测试命令：`.venv/Scripts/python.exe -m unittest discover -s tests`（在 `services/daily-digests` 内运行；Linux 使用 `.venv/bin/python`）。测试中的样例仅供离线验证，生产 worker 没有读取样例的路径。
