# 验收

- CLI 退出码0，manifest.status=success，日期为目标北京时间公历日。
- 主备源都只查询同一天；故障、过期 JSON 和农历错误均失败关闭。
- news 原始数组与 HTML/TXT 顺序一致；条数动态；tip 若存在逐字一致。
- 公历、星期、天文台农历彼此一致；农历记录与新闻源记录分开。
- 桌面16px/手机14px 新闻上下内边距，正文16px/1.8行高，640px米白卡片。
- 原文按钮和灰色说明行均不存在；纯文字来源日期仍在；不下载来源图。
- 默认HTML自包含。CID版本仅供正确设置 MIME 内联图片的授权发送端。
- PDF 是可提取文字；逐条检查提取内容，并把每页渲染为PNG检查中文字体、裁切、换行和分页。
- WeasyPrint 的验证渲染显式应用模板手机规则，因为它不处理屏幕 viewport media features。不能因此宣称真实 Gmail/Outlook/iOS/Android 客户端全部兼容。
- 离线示例只验证复现和一致性，不验证新闻事实真实性或当天在线可用性。
